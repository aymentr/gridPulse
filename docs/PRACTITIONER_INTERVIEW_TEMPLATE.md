# Practitioner Interview Template

Use one copy per **real** interview. Save completed records as
`validation/interview/records/INT-<NNN>.md` and add a line to `validation/interview/INTERVIEW_LOG.md`.

**Rules**

- Never create a record for an interview that did not happen. No placeholder or example participants.
- Record the participant's words and facts; mark your own interpretation separately.
- Do not store names, employers, project names, contact details or anything that identifies a person
  or project unless strictly necessary and consented to. Use the participant code only.
- Ask about the current workflow **first**. Do not mention GridPulse until Section 11.
- Record contrary and negative evidence as carefully as supportive evidence.
